============================================================

- campus_spot_allocator

Use that existing allocator.

Do NOT create another allocator.

Do NOT use COUNT(*).

Do NOT generate a spot using Date.now(), UUIDs, random numbers, etc.

The invariant is:

ONE USER → ONE SPOT
ONE SPOT → ONE USER

If:

then reuse the existing spot.

If:

profiles.spot IS NULL

allocate exactly one spot atomically.

A retry after a failed request must not consume multiple spots for the same user.
